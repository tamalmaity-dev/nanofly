# NanoFly v0.3.20.18-beta — Unified Local Project Templates, Docker Code Area & Advanced Service Configurations

**Release Date:** 2026-05-31  
**Type:** Feature Release & Configuration Persistence  
**Urgency:** Medium  

---

## Summary

This release unifies local folder, Dockerfile, and Docker Compose configurations under a single, highly flexible configuration selector on the project Details page. It also enables full state synchronization and database persistence for 11 advanced configuration options (Docker registry tagging, custom build stages/options, and host-to-container port mapping).

## Key Changes

### 1. Unified Local Project Settings
- Merged local folder, Dockerfile, and Docker Compose configurations into a single, unified renderer.
- This allows changing the build method dynamically for any local folder project service from the dropdown (`BuilderTypeSelect`) without locking the user out.

### 2. Inline Code Area Editors
- Monospaced code editors for `Dockerfile` and `Docker Compose` are now displayed immediately inside the service configuration panel when they are chosen as the build method, matching the creation wizard.

### 3. Advanced Service Configuration Persistence
- Form state initialization and saving handlers now synchronize 11 new database-persisted fields:
  - **Docker Registry**: Docker Registry Image, Docker Registry Tag.
  - **Build Engine**: Base Directory, Dockerfile Location, Docker Build Stage Target, Watch Paths, Custom Docker Options (arguments), and "Use a Build Server?" toggle.
  - **Networking**: Ports Exposes, Port Mappings, and Network Aliases.

## Deployment & Verification Steps

To deploy these updates to your NanoFly server:

1. **Pull the latest codebase** on your server:
   ```bash
   git pull origin main
   ```
2. **Rebuild the backend**:
   ```bash
   make build
   ```
 3. **Restart the NanoFly service**:
   ```bash
   sudo systemctl restart nanofly
   ```
4. **Verify the configuration updates**:
   - Access the service Details page, select a service, and verify you can switch build methods and customize advanced fields.
