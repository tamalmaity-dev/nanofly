# NanoFly v0.3.20.19-beta — Expanded Layout, First-tab Configuration, and Docker Image Build Packs

**Release Date:** 2026-05-31  
**Type:** Feature Release & Layout Optimization  
**Urgency:** Medium  

---

## Summary

This release cleans up the service details tabs layout to put "Configuration" first, removes the hardcoded width restrictions to utilize all right-side blank space, and introduces build pack selection for Docker Image apps so users can switch seamlessly to building from source files.

## Key Changes

### 1. Expanded Layout (Black Space Makeup)
- Removed `maxWidth: 900` from the settings panel container, allowing the form elements and cards to utilize the full width of the parent details panel.

### 2. Configuration Tab Priority
- Reordered tabs on the Service Details panel to place "Configuration" first for application services.
- Opening/selecting a service now redirects to the "Configuration" tab by default instead of "Deployments".

### 3. Build Packs for Docker Image Apps
- Merged the "Docker Image App" layout into the unified local settings builder layout.
- The build method selector is now available on Docker Image services. Switching from "Pre-built Docker Image" to "Dockerfile" or "Docker Compose" will immediately render the monospaced inline code editors, tooltips, and server folder path inputs.

### 4. Removed Redundant Variables Card
- Passed `hideEnvVars={true}` to `<AddServiceConfigFields ... />` inside the Configuration tab.
- This hides the Environment Variables card from the Configuration tab since they are already manageable in a dedicated "Environment Variables" tab.

## Deployment & Verification Steps

To deploy these updates to your NanoFly server:

1. **Pull the latest codebase** on your server:
   ```bash
   git pull origin main
   ```
2. **Rebuild the backend**:
   ```bash
   make build
   ```
3. **Restart the NanoFly service**:
   ```bash
   sudo systemctl restart nanofly
   ```
4. **Verify the configuration updates**:
   - Access the service details page and verify the Configuration tab is opened by default and stretches to fill the panel card.
   - For any Docker Image service, verify the Build Method dropdown can switch to Dockerfile or Docker Compose, rendering their inline code editors instantly.
