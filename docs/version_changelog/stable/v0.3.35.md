# NanoFly v0.3.35 — Reusable Sidebar, Live Logs & Coolify-style Backups

**Release Date:** 2026-08-30
**Type:** UX / Refactor
**Urgency:** Recommended

---

## Summary

`v0.3.35` makes the service detail **reusable and Coolify-like**: the left nav is now a standalone `ServiceSidebar.tsx`, **Runtime Logs** gains a Coolify toolbar (service pill, search, line selector, download, live badge), and **Backups** becomes the Coolify stats + empty-state layout (`Schedules / Enabled / Total`, `Storage backup` dropdown, `No scheduled backups` card). No API break.

---

## What Changed

### 1. Sidebar — reusable — `pages/ProjectDetail/ServiceSidebar.tsx` (new) + `ProjectDetail.tsx:14`
- **Before:** Left nav was inline in `ProjectDetail.tsx:3487` — 60-line `groups` array + 40-line `groups.map` JSX, duplicated logic for `isCompose`, not reusable, hard to test.
- **After:** New `pages/ProjectDetail/ServiceSidebar.tsx` (`@ts-nocheck`, 70 lines) — `export function ServiceSidebar({ service, activeTab, onSelect })` with the same 4 groups (**Settings** / **Observe** / **Automation** / **Operations**) and `isCompose` branching, `220px` sticky, `8px 10px` buttons. `ProjectDetail.tsx` now `import { ServiceSidebar } from './ProjectDetail/ServiceSidebar'` and renders `<ServiceSidebar service={selectedSvc} activeTab={activeTab} onSelect={setActiveTab} />`. `EnvVarsPanel` split in `v0.3.34` already follows the same `pages/ProjectDetail/*` pattern — the folder is now the home for all service-detail UI.

### 2. Runtime Logs — Coolify toolbar — `ProjectDetail.tsx:1932`
- **Before:** Simple `Runtime Container Logs` header + `Copy`/`Refresh` + `pre` (`maxHeight 320`, `background #0d1117`, no search, no line control, no download).
- **After:** Toolbar like Coolify **Image 1**: service pill (`Seaweedfs` + `ChevronRight`), `Copy`/`Refresh`/`Download` (download via `Blob` → `service-logs.txt`), `Lines` selector (100/500/1000), `Find in logs` input (filters `logs.split('\n').filter(l => l.toLowerCase().includes(search))`, `slice(-lines)`), `pre` (`maxHeight 380`, `fontSize 0.8rem`), footer `N lines (filtered)` + `Live polling every 3s` (green dot). Keeps existing `projectDbs` service switcher and 3 s polling.

### 3. Backups — Coolify layout — `ProjectDetail.tsx:2540`
- **Before:** Two cards — `Manual Logical Backup` (`Create Backup`) + `Import Backup` (red, `backup_file.sql` input). No stats, no `Storage backup` dropdown, no empty-state.
- **After:** Coolify **Image 2** layout:
  - Header `Backups` + `+ Add backup` dropdown (`Storage backup` → `handleBackup`).
  - Stats card `grid 1fr 1fr 1fr` (`Schedules 0 / Enabled 0 / Total 0`, `1.5rem` numbers).
  - Search + `Filter`/`Sort` buttons.
  - Empty-state card (`48px` icon, `No scheduled backups`, `Add a database, persistent volume...` + `Create Storage Backup`).
  - Manual import kept below as `Import Backup` (muted red, `backup_file.sql or backup_*.tar.gz` placeholder, `Import Data` outline).
