# NanoFly v0.3.43 — Cloudflare Proxy Detection for Domain DNS Verification

**Release Date:** 2026-08-30
**Type:** Feature
**Urgency:** Recommended

---

## Summary

`v0.3.43` adds Cloudflare-proxied domain detection to DNS verification. Domains behind Cloudflare proxy (Orange Cloud) are now accepted as valid without requiring users to disable the proxy. This matches Coolify's behavior where Cloudflare-proxied domains pass DNS validation automatically.

### 2. `isCloudflareIp()` Function — `handler.go:296-308`

```go
func isCloudflareIp(ipStr string) bool {
    ip := net.ParseIP(ipStr)
    if ip == nil { return false }
    for _, cidr := range cloudflareIPs {
        _, network, err := net.ParseCIDR(cidr)
        if err != nil { continue }
        if network.Contains(ip) { return true }
    }
    return false
}
```

Uses `net.ParseCIDR` + `network.Contains()` for proper CIDR subnet matching (IPv4 and IPv6).

### 3. DNS Verification Now Accepts Cloudflare — `handler.go:193-253`

**Before:** Only accepted direct server IP match.
**After:** Accepts both direct server IP AND Cloudflare proxy IPs.

```go
for _, ip := range ips {
    // Direct server match
    for _, sip := range serverIPs {
        if ip == sip { verified = true }
    }
    // Cloudflare proxy match
    if isCloudflareIp(ip) {
        cloudflareProxied = true
        verified = true
    }
}
```

Returns `cloudflare_proxy: true` in API response when domain is behind Cloudflare.

### 4. Frontend Cloudflare-Aware Messages — `Domains.tsx`

- **Toast:** "DNS verified! Domain is behind Cloudflare proxy. SSL handled by Traefik + Cloudflare."
- **Success:** "Domain is behind Cloudflare proxy (104.x.x.x). SSL handled by Traefik + Cloudflare."
- **Instructions:** "Cloudflare users: You can keep the proxy ON (Orange Cloud)"

## How Coolify Manages Domains

### Domain Addition Flow

1. **User adds domain** (e.g. `https://app.example.com`)
2. **Format validation** — must be valid URL with `http://` or `https://` scheme
3. **Forbidden characters** — backtick, `$`, `;`, `&`, `|`, `<`, `>`, `\`, newlines
4. **Hostname validation** — must be FQDN (contains `.`) or valid IP; single-label rejected
5. **Domain conflict check** — ensures domain not used by another resource

### DNS Verification (Coolify)

**File:** `app/Actions/Shared/CheckDomainDns.php`

1. **Skip conditions** — DNS validation disabled, no server available, multi-server setup, `sslip.io` domain
2. **DNS resolution** — queries A or AAAA record against configured DNS servers
3. **Cloudflare detection** — `isCloudflareIp()` checks if resolved IP is in Cloudflare CIDR
4. **Pass criteria** — resolved IP matches server IP **OR** resolved IP is Cloudflare IP
5. **Custom DNS servers** — configurable via instance settings

```php
// From CheckDomainDns.php
foreach ($records as $record) {
    if (isCloudflareIp($record->getData()) || ($expectedIp && $record->getData() === $expectedIp)) {
        return $this->result('ok', $this->successMessage($server, $expectedIp), $expectedIp);
    }
}
```

### SSL/TLS Handling (Coolify)

- **Always generates own SSL** — regardless of Cloudflare proxy status
- **Two layers when Cloudflare proxied:**
  - Cloudflare edge certificate (managed by Cloudflare)
  - Origin certificate (managed by Traefik/Caddy on Coolify server)
- **Recommended config:** `https://` on Coolify + proxied record on Cloudflare (double SSL, works)

### DNS Mismatch Error Messages (Coolify)

```php
function dnsMismatchGuidanceMessage(?string $targetLabel, ?string $ipForRecordType = null): string
{
    $recordType = dnsRecordTypeForIp($address);
    return "Required DNS record type {$recordType} pointing to {$address}";
}
```

Shows users exactly which record type (A or AAAA) and which IP they need.

### DNS Record Hints (Coolify)

When DNS fails, Coolify generates copy-paste-ready DNS record hints:

```php
$records[] = ['type' => 'A', 'name' => $fqdn, 'value' => $ipv4];
$records[] = ['type' => 'AAAA', 'name' => $fqdn, 'value' => $ipv6];
```

Displayed in a modal with BIND-compatible zone format.

### Domain Connect (Coolify Cloud Only)

Automates DNS record creation via Cloudflare's Domain Connect protocol:
- Builds signed URLs following the Domain Connect specification
- Opens Cloudflare's DNS configuration UI in new tabs
- Automatically creates A records pointing to the Coolify server IP

### Asynchronous DNS Checking (Coolify)

DNS checks run asynchronously via Laravel jobs:
- `CheckDomainDnsJob` with 30s timeout
- Results persisted to `domain_dns_statuses` JSON column
- States: `pending`, `checking`, `ok`, `failed`, `skipped`
