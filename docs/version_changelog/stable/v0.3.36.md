# NanoFly v0.3.36 — Coolify-style GitHub App Wizard & Radix Select Fix

**Release Date:** 2026-08-30
**Type:** UI / Bugfix
**Urgency:** Recommended

---

## Summary

`v0.3.36` replaces the inline GitHub Private App 3-step flow with a polished **4-step Coolify-style wizard** (`GitHubAppWizard.tsx`): App selection, Installation status, Repository browser with search/filter, and Configuration. Also fixes a Radix UI `Select.Item` empty-string crash that broke GitHub App repo selection on page load.

---

## What Changed

### 1. GitHub App Wizard — `pages/ProjectDetail/GitHubAppWizard.tsx` (new) + `ProjectDetail.tsx`
- **Before:** Inline 3-step flow in `AddServiceForm` (`select-app` → `select-repo` → `configure-app`) — no step indicator, no search/filter, no installation status guidance, dead code (`repos`, `selectedRepoUrl`, `loadingRepos`, `handleSelectApp`, `refreshRepos`).
- **After:** Standalone `GitHubAppWizard.tsx` component with 4-step visual indicator (numbered circles + progress line):
  1. **GitHub App** — Installed apps (green badge), pending apps (yellow badge with "Needs installation"), inline "Create New App" form (name input → manifest redirect).
  2. **Installation** — Step shown only for uninstalled apps. Instructions (5-step list), "Install on GitHub" button (opens GitHub), "Check Installation" refresh button.
  3. **Repository** — Scrollable repo list with search/filter input, refresh button, "Manage on GitHub" link, hover states, radio-style selection.
  4. **Configuration** — Repository info display + "Create Service" button. Full config available in service settings after creation.
- Dead code removed from `AddServiceForm`: `repos`, `selectedRepoUrl`, `loadingRepos` state; `handleSelectApp`, `refreshRepos` functions.

### 2. Radix Select Empty-String Fix — `AddServiceConfigFields.tsx:837,840` + `GitSourcePanel.tsx:142,145`
- **Before:** `<SelectItem value="">-- Webhook push to deploy (Auto-link) --</SelectItem>` — Radix UI rejects empty-string `value` on `Select.Item`, throws `Uncaught Error` on page load.
- **After:** Sentinel value `__auto-link__` used instead, converted back to `''` in `onValueChange` handler (`val === '__auto-link__' ? '' : val`). Both `AddServiceConfigFields.tsx` (GitHub repo dropdown) and `GitSourcePanel.tsx` (service source panel) fixed.
