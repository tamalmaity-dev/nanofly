# NanoFly v0.3.32 — Compose Storage & Env Fixes + Left Nav Polish

**Release Date:** 2026-08-30
**Type:** UX / Bugfix
**Urgency:** Recommended

---

## Summary

`v0.3.32` fixes two regressions from `v0.3.31` where **Persistent Storage** and **Environment Variables** were hidden for Docker Compose services. Like Coolify, they are now **visible and read-only** — parsed directly from your `docker-compose.yml` — with the yellow banner *"Service volume mounts are read-only here. Edit the Docker Compose file..."*. Ports for compose services now correctly show the compose file's ports (`:8333, :8888`) instead of `:8080`, and the service URL (`http://200.141.9.187:8333`) follows the first compose port.

---

## What Changed

### 1. Persistent Storage & Env Vars for compose — now read-only from compose file
- **Before (`v0.3.31`):** `isCompose ? [] : [...]` hid both tabs for compose → `seaweedfs` showed "No storage found" even though `seaweedfs-data:/data` was in the compose file. Users had to guess where to edit.
- **After:** Both tabs are always visible:
  - **Persistent Storage** (`ProjectDetail.tsx:3557`): when `isCompose`, renders a yellow banner + a per-service grouped table (`Seaweedfs | Volumes (1) | Source Path → Destination Path`) parsed via `yamlLoad(docker_compose_content).services[].volumes` (`src:dst` split). No `Add` button; volumes are defined in the compose file and added to the stack via `normalizeComposeVolumes` (`seaweedfs-data`).
  - **Environment Variables** (`ProjectDetail.tsx:3605`): when `isCompose`, renders a yellow banner + per-service grouped tables (`Seaweedfs | 3 vars | Key → Value`) parsed from `services[].environment` (supports both ` - KEY=VAL` list and `KEY: VAL` mapping). No `Add`/`Bulk Import`; edit the compose file.
- For non-compose `docker run` services, the existing `VolumesPanel`/`EnvVarsPanel` (editable) is unchanged.

### 2. Port & URL for compose — derived from compose file
- **Before:** Top badge `:{selectedSvc.port}` showed `:8080` (default) and `http://...:8080` for `seaweedfs`, which has `8333:8333, 8888:8888, ...` in compose.
- **After:** 
  - Badge (`ProjectDetail.tsx:3322`): when `isCompose`, `yamlLoad` collects all `services[].ports`, extracts host ports via `split(':')[0].replace(/[^0-9]/g,'')`, dedupes, shows `:8333, :8888` (up to 3).
  - URL (`ProjectDetail.tsx:3271`): for compose `app` without a custom domain, `httpUrl` is now the first compose host port (`http://200.141.9.187:8333`) instead of `selectedSvc.port`.

### 3. Left nav — already grouped, now complete
- `v0.3.31` grouped the 12 tabs into **Settings / Observe & troubleshoot / Automation / Operations** with `220px` sticky column. `v0.3.32` keeps the grouping but now includes **Persistent Storage** and **Environment Variables** for compose (so the nav matches Coolify's Image 1 where both tabs are visible with `Seaweedfs` sub-items).
- **Compose** tab remains for the compose file + **Compose resources** table (`Resource | Image | Status`).
